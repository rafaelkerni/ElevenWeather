## MSN / Bing Weather (optional, not bundled)

The optional MSN icon set is not included in this repository or in its releases. It belongs to Microsoft's Bing Weather app: when you select it in the menu, ElevenWeather copies the icons from the copy of that app already installed on your own Windows machine into `%AppData%\ElevenWeather\Icons\Msn\`. Nothing is downloaded or redistributed — see the main [README](README.md#-weather-icons) for details.
